# High School Principal — Unity Mobile Game Case Study

A portfolio case study from **David Chukwunyerem Okoro**, Senior Unity Game Developer and founder of **DRIM LLC**.

This repository is kept as a public reference for an earlier Unity project. My current work is focused on mobile gameplay systems, hybrid-casual prototyping, multiplayer, SDK integrations, optimization and fast full-cycle delivery.

## What I build

- Unity / C# gameplay systems
- Mobile controls, UI and progression
- Rapid prototypes and publisher-ready builds
- Multiplayer systems with Photon PUN 2, Mirror and Unity Netcode
- SDK, analytics and monetization integrations
- Performance profiling, bug fixing and production cleanup

## Recent work

### Cannon Demolish Sort
Hybrid-casual puzzle prototype with 60 playable levels where color sorting drives physical voxel demolition.

Mobile hybrid-casual racing prototype built around launch control, steering, boosts, rivals and obstacle-filled tracks.

Client Unity game later published by Crazy Labs. A strong proof point for fast mobile production and client handoff.

### Bullet Paint / Hoop Sort
Content-driven mobile puzzle projects with 700 unique Bullet Paint levels and 1,000 Hoop Sort levels.
